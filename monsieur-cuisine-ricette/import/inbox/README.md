# Inbox

Metti qui gli screenshot delle ricette Bimby (anche più ricette insieme). Poi in Claude Code: `/importa-ricette`.

Per un buon risultato: uno screenshot della sola scheda (ingredienti e preparazione, senza il resto della pagina)
e, se vuoi la foto, uno screenshot a parte della foto. Le pagine intere molto lunghe vengono rimpicciolite e il testo
diventa difficile da leggere.

- `../ok/<id>/` ricette importate (gli screenshot restano come archivio)
- `../failed/<nome>/` ricette non importate, con `motivo.txt`
