# Ricette per Monsieur Cuisine Connect

Web app personale per consultare, da un tablet in cucina, ricette pensate per il Bimby tradotte in
istruzioni passo passo per il Monsieur Cuisine Connect.

Obiettivi:
- elenco ricette con filtri per tipologia e paese, ricerca per ingredienti
- scheda ricetta (foto, porzioni, tempo, ingredienti) e modalità "Inizia" passo passo
- preferiti
- "cosa ho in frigo": ricette realizzabili con gli ingredienti disponibili

Riferimenti: [conversione Bimby → Connect](docs/conversione-bimby-connect.md)
